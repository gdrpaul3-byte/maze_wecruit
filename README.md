# 미로찾기 (Maze)

의존성 없는 단일 HTML 파일 미로찾기 게임. `maze.html`을 브라우저로 열면 바로 실행됩니다.

## 플레이

- 좌상단 캐릭터에서 출발해 우하단 초록 문에 도착하면 클리어
- 조작: 방향키 또는 `WASD` / 모바일은 스와이프 및 화면 방향 패드
- 클리어할 때마다 레벨이 오르고 미로가 커집니다
- 이동 횟수와 경과 시간을 기록합니다

## 난이도

| | 시작 크기 | 레벨당 증가 | 최대 | 지름길 |
|---|---|---|---|---|
| 쉬움 | 6×6 | +1 | 14×14 | 막다른 길 45% 개방 |
| 보통 | 8×8 | +2 | 22×22 | 12% |
| 어려움 | 12×12 | +2 | 30×30 | 없음 |

"지름길"은 막다른 길의 벽을 일부 터서 되돌아 나오는 구간을 줄이는 방식입니다. 벽을 제거하기만 하므로 길이 막히는 경우는 없습니다.

## 구현

- 재귀적 백트래킹(iterative DFS)으로 매번 다른 미로를 생성 — 모든 칸이 연결되어 해가 항상 존재합니다
- 캔버스 2D 렌더링, 캐릭터는 도형 조합으로 그리며 좌우 이동 시 방향이 바뀝니다
- 다크모드 자동 대응 (`prefers-color-scheme`)
